## 3. 关系判例集（Study A 金标准关系对候选）

| 判例 | 预期关系 | 检验点 |
|---|---|---|
| C17 × C06 | Complement | 相似主题 ≠ Support：金额信息，但锚点不同（明细折叠与否 vs 披露时机） |
| C15 × C13 | Trade-off | 安全线索 / 支付 logos 与主 CTA 视觉层级竞争；化解 = 紧邻表单的低层级排布 |
| C15 × C05 | Support 候选 | 信任徽章堆砌与优惠干扰同耗注意力（判定锚点：同一区域、同向判断） |
| C19 × C15 / C16 | Trade-off | 去干扰（任务连续性）vs 留信任线索（信任感知）；化解 = 紧凑的"结算专用信任区" |
| C20 × 支付方式多样性 | 表面矛盾、条件不同 | 多样性解决"有没有"，C20 管"默认适配 + 切换成本"；淘宝案例证明可同时成立 |
| C20 × C11 | Dependency 候选 | 淘宝案例：切换需退出流程 → 返回后状态是否保留属 C11 范围；先解决入口可达性，再验证状态保持 |
| C18 × C04 | Complement 候选 | 入口可发现（C04）+ 规则可知（C18）共同支撑优惠的有效使用 |
