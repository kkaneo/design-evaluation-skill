# Design Evaluation Skill · 自适应多视角 UI/UX 设计评审（初版 v0.1）

**一句话定位**：根据具体设计任务动态组织有依据的评价视角，通过独立证据化评审、跨视角关系分析与 QOC 决策支持，帮助设计师理解问题、比较方案、完成迭代。

**研究主张**：不是证明"多个 AI 专家比一个 AI 更好"，而是检验——通过任务适配的专业评价视角组织、独立证据化评审与跨视角关系推理，能否让设计师在有限时间内更准确地理解复杂 UI/UX 问题，形成更有依据的修改方案，并最终改善真实用户体验。

## 快速上手（三步）

1. 设计师填写 `templates/task-card.md`（任务卡 + Flow Spec，10–15 分钟）
2. 按 `SKILL.md` 工作流执行评审：M1 视角配置（设计师确认）→ M2 独立评审 → M3 关系分析 → M4 QOC
3. 设计师修改设计稿后回填 M5 迭代记录（关联 Issue ID + 取舍理由）

不做通用 audit 工具 / 不依赖浏览器自动化 / AI 不打最终分；E1–E3 证据分级与措辞纪律；视角由 AI 提议、设计师确认（最终确认权在人）；二手引述仅提供视角参考，不单独支撑问题判定。
